# GCMC API (hawkma)

Backend for the GCMC consultancy platform — Laravel 13 modular monolith.

- Full implementation plan: [`docs/BACKEND_IMPLEMENTATION_PLAN.md`](docs/BACKEND_IMPLEMENTATION_PLAN.md)
- Frontend integration guide: [`docs/FRONTEND_API_GUIDE.md`](docs/FRONTEND_API_GUIDE.md)
- Deviations from the plan: [`docs/DECISIONS.md`](docs/DECISIONS.md)

## Requirements

- PHP 8.3+ (developed on 8.4) with the usual Laravel extensions + GD
- Composer 2
- MySQL 8+
- Node 18+ (only for running the Postman collection with newman)

## Installation

```sh
composer install
cp .env.example .env
php artisan key:generate
```

Create the database and configure `.env` (see below), then:

```sh
php artisan migrate:fresh --seed
php artisan serve          # http://localhost:8000
```

## .env

The important keys:

| Key | Meaning |
|---|---|
| `DB_*` | MySQL connection |
| `APP_LOCALE` / `APP_FALLBACK_LOCALE` | `ar` / `en` |
| `ADMIN_FRONTEND_URL` / `CLIENT_FRONTEND_URL` | Used in emails (reset password, report links) |
| `CORS_ALLOWED_ORIGINS` | Comma-separated frontend origins |
| `QUEUE_CONNECTION` | `database` locally; notifications are queued |
| `MAIL_MAILER` | `log` locally (mails land in `storage/logs/laravel.log`) |
| `PAYMENT_GATEWAY` | `fake` or `moyasar` (see below) |
| `MEETING_DRIVER` | `fake` or `google` (see below) |
| `BOOKING_SLOT_MINUTES`, `BOOKING_DURATION_MINUTES`, `BOOKING_MIN_NOTICE_MINUTES`, `BOOKING_MAX_ADVANCE_DAYS`, `BOOKING_PAYMENT_HOLD_MINUTES`, `BOOKING_CLIENT_CANCEL_HOURS` | Booking rules |
| `SUPER_ADMIN_EMAIL` / `SUPER_ADMIN_PASSWORD` | Seeded admin account |

## Queue worker and scheduler

Notifications (booking confirmations, report ready, …) are queued, and two
commands run on the scheduler:

```sh
php artisan queue:work        # processes the notification jobs
php artisan schedule:work     # bookings:expire-pending (every minute),
                              # subscriptions:expire (daily 00:05)
```

In production use a real queue driver and a cron entry for
`php artisan schedule:run`.

## Tests

```sh
php artisan test              # full suite (470 tests)
php artisan test --parallel   # faster, uses paratest
./vendor/bin/pint --test      # code style
```

Tests use an in-memory/SQLite-free MySQL test database via `RefreshDatabase`;
no real Moyasar or Google calls are made (`Http::preventStrayRequests()`).

## Postman

```sh
# serve the app with the dedicated postman environment (separate database):
mysql -u root -e "CREATE DATABASE IF NOT EXISTS gcmc_postman"
php artisan migrate:fresh --seed --env=postman
APP_ENV=postman php artisan serve --port=8000

# then, in another terminal:
npx newman run postman/GCMC-API.postman_collection.json \
  -e postman/GCMC-Local.postman_environment.json \
  --working-dir postman --env-var ci=true
```

Import `postman/GCMC-API.postman_collection.json` and one of the environment
files into Postman to explore by hand; every request has a saved real example
response. The collection is generated by
`scripts/build-postman-collection.php`; examples are filled from a newman
report by `scripts/postman-fill-examples.php`.

## Switching to the real drivers

### Moyasar (payments)

```
PAYMENT_GATEWAY=moyasar
MOYASAR_SECRET_KEY=sk_live_…
MOYASAR_PUBLISHABLE_KEY=pk_live_…
MOYASAR_WEBHOOK_SECRET=…
PAYMENT_CALLBACK_URL=https://app.gcmc.sa/bookings/payment-callback
```

The webhook URL to register in the Moyasar dashboard is
`POST {APP_URL}/api/v1/webhooks/payments/moyasar`. With `PAYMENT_GATEWAY=fake`
the tokens `tok_fake_success` / `tok_fake_3ds` / `tok_fake_declined` simulate
the gateway.

### Google Meet (meetings)

```
MEETING_DRIVER=google
GOOGLE_SERVICE_ACCOUNT_JSON=/absolute/path/to/service-account.json
GOOGLE_CALENDAR_IMPERSONATE=consultancy@gcmc.sa   # workspace user to impersonate
GOOGLE_CALENDAR_ID=primary
```

With `MEETING_DRIVER=fake`, meetings get `https://meet.google.com/fak-…` URLs
and no Google calls are made.
