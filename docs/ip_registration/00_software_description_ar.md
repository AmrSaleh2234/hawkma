## 3. تصنيف المصنف

وفق تعريفات الدليل الاسترشادي لحماية حقوق المؤلف في البرمجيات (SAIP):

- **برنامج الحاسب الآلي / برمجيات الحاسب الآلي**: الكود المصدري الكامل (خلفي وأمامي وجوال).
- **منصة رقمية**: النظام ككل يؤدي وظيفة محددة مباشرة للمستخدم النهائي (حجز استشارات، إدارة اشتراكات، تقارير).
- **تطبيق إلكتروني**: تطبيق الجوال (iOS / Android) الخاص بالعملاء.
- **قاعدة بيانات**: قاعدة البيانات العلائقية (MySQL) التي تخزن بيانات العملاء، الاستشاريين، الحجوزات، الباقات، المدفوعات، التقارير.

## 4. وصف المصنف ووظائفه

منصة "حوكمة" هي منظومة برمجية متكاملة تُقدَّم من خلالها خدمات استشارية في مجالات **الحوكمة، الامتثال، الاستشارات الإدارية، واستقطاب المواهب الوظيفية**، لشركات ومنشآت الأعمال في المملكة العربية السعودية. تتيح المنصة للعميل (منشأة الأعمال):

- الاشتراك في **باقات استشارية** شهرية (حديدية / فضية / ذهبية) بعدد محدد (أو غير محدود) من الجلسات الاستشارية الشهرية.
- حجز **جلسة استشارية مباشرة** مع مستشار معتمد دون المرور بباقة (نموذج "زيارة" بسعر مقطوع لكل جلسة)، عبر معالج حجز من عدة خطوات: اختيار الباقة/المستشار → تسجيل الدخول → اختيار التاريخ والوقت المتاح → اختيار الموقع → الدفع → التأكيد.
- عقد الجلسة الاستشارية أونلاين عبر رابط **Google Meet** يُنشأ تلقائيًا بعد تأكيد الحجز والدفع.
- استلام **تقرير مكتوب** من المستشار بعد انتهاء الجلسة عبر حسابه في المنصة وبالبريد الإلكتروني.
- إدارة بيانات الشركة (الفروع/المواقع)، وسائل الدفع المحفوظة، وسجل الحجوزات والتقارير والاشتراكات.

كما توفر المنصة **لوحة تحكم إدارية** للموظفين الإداريين والمستشارين تتيح:

- إدارة المستخدمين، الأدوار، والصلاحيات (نظام صلاحيات دقيق قائم على الأدوار).
- إدارة بيانات المستشارين (الملف الشخصي، أوقات التوفر، الإجازات، العملاء، الحجوزات، التقارير).
- إدارة الباقات الاستشارية والأسعار.
- إدارة المدفوعات عبر بوابة الدفع السعودية "Moyasar" (مدى، فيزا، ماستركارد، Apple Pay).
- متابعة طلبات الانضمام كمستشارين، التقييمات، تذاكر الدعم الفني، سجل الأنشطة، والإشعارات.
- لوحة إحصائيات (Dashboard) تعرض مؤشرات الأداء الرئيسية.

### مكونات المنصة الثلاثة (تُشكّل منظومة واحدة مترابطة عبر واجهة برمجية REST API موحدة):

1. **الخلفية البرمجية (Backend API)** — المصدر الوحيد للبيانات والمنطق التجاري، ويخدم الموقعين التاليين وتطبيق الجوال عبر نقاط اتصال (Endpoints) موحدة.
2. **الواجهة الأمامية (Web Frontend)** — لوحتا تحكم ويب (إدارية/استشارية، وعميل) + الصفحة التسويقية العامة.
3. **تطبيق الجوال (Mobile App)** — تطبيق جوال للعملاء (iOS و Android) لإدارة الحجوزات والتقارير من الهاتف.

## 5. لغات البرمجة وأنظمة التشغيل اللازمة للتشغيل

| المكوّن | لغة البرمجة / إطار العمل | قاعدة البيانات | بيئة التشغيل اللازمة |
|---|---|---|---|
| **الخلفية (Backend)** | PHP 8.4 — إطار عمل Laravel 13 (معماري معياري Modular عبر حزمة nwidart/laravel-modules)، مصادقة عبر Laravel Sanctum، صلاحيات عبر Spatie Laravel-Permission | MySQL 8 | خادم ويب (Nginx/Apache) + PHP-FPM 8.4+، نظام تشغيل Linux (أو أي نظام يدعم PHP)، Composer لإدارة الحزم |
| **الواجهة الأمامية (Frontend)** | TypeScript / React 19 — إطار عمل Next.js 16 | — (تستهلك واجهة الـ API) | Node.js (بيئة تشغيل JavaScript)، متصفح ويب حديث لتشغيل الواجهة الناتجة |
| **تطبيق الجوال (Mobile)** | Dart — إطار عمل Flutter (Flutter BLoC لإدارة الحالة) | — (تستهلك واجهة الـ API) | نظام Android أو iOS على جهاز المستخدم النهائي، Flutter SDK لبيئة التطوير والبناء |

**أدوات ومكتبات مساعدة رئيسية:** Google Calendar API (لإنشاء روابط Google Meet تلقائيًا)، بوابة الدفع Moyasar، Spatie Media Library (إدارة الملفات والصور)، Laravel Echo/Pusher (الإشعارات الفورية في الواجهة الأمامية).

## 6. التصرفات الواردة على المصنف (إن وجدت)

لا توجد تصرفات (عقود، تراخيص، تنازلات) واردة على المصنف حتى تاريخه. مقدم الطلب **عمرو صالح أنور محمد** هو المؤلف وصاحب الحق على المكونات الثلاثة للمنظومة (الخلفية، الواجهة الأمامية، تطبيق الجوال)، وطلب التسجيل يُقدَّم باسمه فقط عن المنظومة كاملة.
